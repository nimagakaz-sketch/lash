# ✨ Beauty Salon: Telegram Mini App & Bot (MVP)

Готовый к деплою MVP Telegram-бота и Telegram Mini App (WebApp) для онлайн-записи клиентов в бьюти-сфере (**наращивание ресниц, брови, маникюр, ламинирование, массаж, косметология**).

Главная бизнес-фича: **полный ребрендинг под любого локального мастера или салон за 2 минуты** через один файл `beauty_config.json`.

---

## 💎 Особенности и стек технологий

- **Backend в одном процессе**: **Python 3.11+**, **FastAPI** + **aiogram 3.x**. FastAPI раздаёт статику Mini App и REST API, aiogram обрабатывает команды бота, уведомления мастеру и напоминания клиентам.
- **Инфраструктура базы данных**: **Supabase** (PostgreSQL) с автоматическим fallback на локальный **SQLite** (`beauty.db`), если ключи Supabase не заданы в `.env`. Демо запускается мгновенно из коробки!
- **Frontend Mini App**: Чистый Vanilla HTML5, CSS3, JavaScript без сборщиков (Webpack/Vite/React).
- **Эксклюзивный Liquid Glass тулбар**: Использован фирменный компонент из набора *Liquid Glass Kit* (@vovnx) — реалистичная жидкая капля, пружинная физика, SVG-преломление (`feDisplacementMap`), тактильный отклик `Telegram.WebApp.HapticFeedback`.
- **Готов к деплою на Render**: Реализован эндпоинт `GET /health` (`{"status": "ok"}`) с кодом 200 для пинга через **UptimeRobot**, порт считывается из переменной `$PORT`.
- **Защита API**: Валидация `Telegram.WebApp.initData` через HMAC-SHA256 по токену бота.

## 🚀 Быстрый запуск локально за 30 секунд

```bash
# 1. Перейдите в папку проекта
cd lashers

# 2. Создайте и активируйте виртуальное окружение
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Скопируйте конфигурацию окружения
cp .env.example .env

# 5. Запустите сервер
python3 main.py
```

После запуска:
- Откройте в браузере: **`http://localhost:8000`** — клиентский интерфейс онлайн-записи.
- Откройте в браузере: **`http://localhost:8000?admin=1`** — откроется 4-я вкладка **«Кабинет мастера»** (управление записями, блокировка окон, статистика, редактирование прайса).
- Эндпоинт проверки здоровья: **`http://localhost:8000/health`**.

## 📱 Функционал Telegram Mini App

### 1. Вкладка «Услуги и запись»
- **Карточка мастера**: Аватар, имя, рейтинг, график работы и кликабельный адрес с подсказкой прохода.
- **Горизонтальный фильтр категорий**: Быстрое переключение с плавным откликом.
- **Карточки услуг**: Название, цена, время выполнения, описание, бейджи «Хит» / «Тренд» / «Выгода».
- **Пошаговый Bottom Sheet онлайн-записи**:
  1. Карточка выбранной услуги.
  2. Интерактивная лента дат на 14 дней вперёд (с днями недели).
  3. Свободные временные окна (динамический расчёт с учётом длительности процедуры, существующих записей и перерывов).
  4. Форма с автоматическим заполнением имени из Telegram, телефоном, чекбоксами «Нужно снятие (+30 мин, +500 ₽)» и «Аллергия / особенности».
  5. Экран подтверждения с кнопкой генерации файла календаря **.ICS** (добавление в Apple Calendar / Google Calendar) и прямой кнопкой «Написать мастеру».

### 2. Вкладка «Портфолио»
- Сетка работ мастера из конфига/БД.
- Клик по фото открывает полноэкранный просмотр с категорией и кнопкой **«Хочу так же ✨»**, которая сразу переводит клиента к выбору даты и времени для этой услуги.

### 3. Вкладка «Мои визиты»
- Разделение на «Предстоящие» и «Прошедшие».
- Статусы записей: ⏳ Ожидает подтверждения, ✅ Подтверждена, ❌ Отменена, ✨ Завершена.
- **Отмена визита клиентом**: разрешена не позднее чем за 3 часа до визита. При отмене слот моментально освобождается, а мастер получает уведомление в Telegram.

### 4. Встроенный Кабинет мастера (Админ-панель)
*Появляется как 4-я вкладка в Liquid Glass тулбаре только для `admin_ids`.*
- **Расписание на день**: Список клиентов с временем, услугой, суммой, телефоном и прямой кнопкой **«💬 Чат в Telegram»**.
- **Кнопки управления**: «✅ Подтвердить» и «❌ Отклонить» статус прямо из Mini App.
- **Блокировка окон**:
  - Блокировка отдельного часа (обед, перерыв).
  - Закрытие целого дня (выходной/отпуск).
  - Список заблокированных слотов с кнопкой разблокировки.
- **Управление прайсом**: добавление, редактирование и удаление услуг без правок кода.
- **Управление портфолио**: добавление новых фото прямо по URL и удаление старых.
- **Мини-статистика**: Выручка за текущий месяц, количество подтвержденных визитов, уникальных клиентов и общее число заявок.

## 🤖 Функционал Telegram-бота (`aiogram 3.x`)

1. **Команда `/start`**:
   - Красивое приветствие от имени студии.
   - Кнопка `WebAppInfo` «✨ Записаться онлайн».
   - Кнопка «📋 Прайс и контакты».
   - Кнопка «🗓 Мои визиты».
2. **Мгновенные уведомления мастера**:
   - При новой записи мастер получает подробное сообщение с деталями (имя, @username, телефон, процедура, дата, время, снятие, аллергия, комментарий).
   - Под сообщением inline-кнопки: **«✅ Подтвердить»** и **«❌ Отклонить»**, а также **«💬 Написать клиенту»**.
   - При нажатии статус обновляется в базе данных, а клиенту уходит персональное уведомление с адресом студии.
3. **Автоматические напоминания (`asyncio` scheduler)**:
   - За 24 часа до визита: напоминание с кнопками «✅ Подтверждаю визит» и «❌ Не смогу прийти».
   - За 2 часа до визита: финальное напоминание с адресом и временем.

## 🌐 Деплой на Render за 5 минут

1. Создайте репозиторий на GitHub и загрузите файлы проекта:
   ```bash
   git init
   git add .
   git commit -m "Beauty Salon Mini App & Bot MVP"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/beauty-bot.git
   git push -u origin main
   ```
2. Перейдите на [Render.com](https://render.com) и нажмите **New Web Service**.
3. Выберите ваш репозиторий.
4. Настройки:
   - **Environment**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT`
5. В разделе **Environment Variables** добавьте:
   - `BOT_TOKEN`: токен вашего бота от @BotFather.
   - `ADMIN_IDS`: ваш Telegram ID (узнать можно в боте `@userinfobot`).
   - `WEBAPP_URL`: адрес вашего сервиса на Render (например, `https://beauty-bot.onrender.com`).
   - `ENVIRONMENT`: `production`
6. Нажмите **Deploy Web Service**.
7. После успешного деплоя скопируйте URL и зарегистрируйте Menu Button в @BotFather:
   - Напишите `@BotFather` -> `/mybots` -> выберите бота -> **Bot Settings** -> **Menu Button** -> **Configure menu button** -> отправьте URL `https://beauty-bot.onrender.com` и текст кнопки `Записаться онлайн ✨`.
8. Настройте бесплатный пинг через [UptimeRobot.com](https://uptimerobot.com):
   - Добавьте монитор типа **HTTP(s)** на URL `https://beauty-bot.onrender.com/health` с интервалом каждые 5-10 минут. Это предотвратит засыпание бесплатного тарифа Render!

```

├── beauty_config.json       # Единый конфигурационный файл для ребрендинга за 2 минуты

├── static/
```
